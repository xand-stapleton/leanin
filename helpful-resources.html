Helpful Resources

A small set of places I've found useful while learning Lean and mathlib

Start Here

lean4.dev is a very good first stop. It presents Lean 4 as both a functional programming language and an interactive theorem prover. It's by far my favourite resource.

The site brings together a language guide, a tactics reference, a course, installation notes, examples, and links out to the wider Lean community.
