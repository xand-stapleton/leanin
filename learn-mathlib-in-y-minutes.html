Cheat sheet

Learn mathlib in Y Minutes

A quick, example-first tour of the habits you need to start reading and writing small Lean 4 proofs with current mathlib.

Learn X in Y Minutes is my favourite way to learn a new language, I did it with Go and went on to co-write both GoBlocks and RugTac with it. LXIYM is extremely terse and practical, and if you know at least one language like Python or C or something, then when you learn a new language you're just learning syntax rather than how to code. I wanted to emulate that style for mathlib: not a replacement for the docs by any means, but hopefully helpful.

One File

-- A tiny mathlib file usually starts like this.
import Mathlib

-- Ask Lean what something is.
#check Nat.Prime
#check Set.ext
#check Finset.sum_range_succ
#check Polynomial

-- Ask Lean to compute a small expression.
#eval (List.range 5).map Nat.succ

Propositions

-- Proofs are programs. Assumptions become local names.
example (p q : Prop) : p ∧ q → q ∧ p := by
  intro h
  exact ⟨h.2, h.1⟩

-- Split goals with constructors.
example (p q : Prop) : p → q → p ∧ q := by
  intro hp hq
  constructor
  · exact hp
  · exact hq

-- Unpack existentials and build new ones.
example : (∃ n : Nat, n = 3) := by
  use 3

Sets

open Set

-- An explicit universe keeps the element type fully general.
universe u

-- To prove sets equal, prove they have the same elements.
example {α : Type u} (s t : Set α) : s ∩ t = t ∩ s := by
  ext x
  simp only [Set.mem_inter_iff, and_comm]

-- Set-builder notation is common in mathlib.
#check {n : Nat | Nat.Prime n}

Rewriting

-- `rw` rewrites with equalities and named theorems.
example (a b : Nat) (h : a = b) : a + 1 = b + 1 := by
  rw [h]

-- `simp` uses mathlib's simplification database.
example (n : Nat) : n + 0 = n := by
  simp

-- `simpa` is `simp`, then close the goal.
example (n : Nat) : 0 + n = n := by
  simpa

Algebra

-- Algebraic identities are usually tactic territory.
example (x y : Int) : (x + y)^2 = x^2 + 2*x*y + y^2 := by
  ring

-- Ordered algebra often uses existing monotonicity lemmas.
example (a b c : Int) (h : a ≤ b) : a + c ≤ b + c := by
  exact add_le_add_right h c

-- `linarith` handles many linear arithmetic goals.
example (a b : Int) (h : a ≤ b) : a + 1 ≤ b + 1 := by
  linarith

Finite Objects

open BigOperators

-- Finsets are finite sets with computable membership.
#check Finset.range
#check Finset.card
#check Finset.sum_range_succ

-- Sums over finite ranges are everywhere in mathlib.
example : (∑ i in Finset.range 4, i) = 6 := by
  norm_num

Finding Theorems

-- `#check` works if you already know the name.
#check Nat.coprime_self_add_right

-- Names are often namespaces plus descriptive words:
--   Nat.Prime
--   Set.Subset
--   Finset.card_union
--   Polynomial.eval

-- When stuck, inspect the goal state after each line.
-- In an editor, the infoview is part of the proof.

Imports and Namespaces

-- `import Mathlib` is convenient while learning.
-- Later, narrower imports make files faster and clearer.

import Mathlib

open Set
open BigOperators

-- `namespace` and dot notation help you guess names.
#check Nat.gcd
#check Int.ofNat
#check Real.sqrt

The Main Loop

-- 1. State a small theorem.
-- 2. Put the cursor after `by`.
-- 3. Read the goal.
-- 4. Introduce assumptions with `intro`.
-- 5. Split structured goals with `constructor`.
-- 6. Rewrite with `rw`, simplify with `simp`, calculate with `ring`.
-- 7. Search docs when the goal is clearly asking for a library theorem.
