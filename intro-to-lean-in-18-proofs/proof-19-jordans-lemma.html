Lean Statement

Tendsto
  (fun R ↦ ∫ θ in 0..Real.pi,
    upperSemicircleIntegrand a R f θ)
  atTop (𝓝 0)
Read this as: fix $a>0$ and integrate $e^{iaz}f(z)$ anticlockwise along the upper semicircle of radius $R$. If $f$ is bounded on that arc by a nonnegative quantity $M(R)$, and $M(R)\to0$, then the contour integral tends to $0$ as $R\to\infty$.

Write a point of the upper semicircle as $z=Re^{i\theta}$, where $0\le\theta\le\pi$. Its differential contributes a factor of norm $R$, while

\[\left|e^{iaz}\right|=e^{-aR\sin\theta}.\]

The sine vanishes at the endpoints, so bounding the exponential by $1$ would leave an unwanted factor of $R$. Instead, split the arc at $\pi/2$. On the left half, the sine inequality $\sin\theta\ge2\theta/\pi$ gives a bound we can integrate explicitly. Set $k=2aR/\pi>0$; then

\[ \begin{aligned} \left|\int_0^{\pi/2} F_R(\theta)\,d\theta\right| &\le RM(R)\int_0^{\pi/2} e^{-k\theta}\,d\theta\\ &=\frac{RM(R)}{k}\left(1-e^{-k\pi/2}\right)\\ &\le\frac{\pi}{2a}M(R), \end{aligned} \]

where $F_R(\theta)$ is the parameterised contour integrand. The radius cancels against $k$: this is the key estimate. On the right half, substitute $u=\pi-\theta$ and use $\sin(\pi-u)=\sin u$ to reuse the same bound.

Adding the two halves gives

\[\left|\int_{\text{upper semicircle}} e^{iaz}f(z)\,dz\right|\le\frac{\pi}{a}M(R).\]

Since $M(R)\to0$, the contour integral tends to zero.

Why This Proof Matters

Jordan's lemma is the standard device that makes many Fourier- and Laplace-type contour integrals work. It shows precisely how the exponential factor damps the large semicircular arc, leaving only the real-axis integral and the residues inside the contour.

In Lean, the useful pattern is to prove one quantitative estimate, reuse it through a change of variables, and finish with the squeeze theorem. We build the arc estimate below from the sine inequality and elementary calculus; no library version of Jordan's lemma is invoked.

Schematic Outline

  1. Parameterise the upper semicircle and compute the norm of its integrand.
  2. Evaluate $\int_0^b e^{-kx}\,dx$ using its antiderivative.
  3. Use $2\theta/\pi\le\sin\theta$ to bound the left-half integral by $\frac{\pi}{2a}M(R)$.
  4. Reflect the right half using $u=\pi-\theta$ and reuse the same estimate.
  5. Split the full integral and apply the triangle inequality to obtain $\frac{\pi}{a}M(R)$.
  6. Apply the squeeze theorem, since this bound tends to zero.

import Mathlib

open MeasureTheory Filter Set
open scoped Real Topology Interval

namespace LeanIn

/-- The contour integrand after writing `z = R * exp (θ * I)`.
The factor `z * I` is the tangent `dz/dθ`, so its norm contributes `R`. -/
noncomputable def upperSemicircleIntegrand
    (a R : ℝ) (f : ℂ → ℂ) (θ : ℝ) : ℂ :=
  (circleMap 0 R θ * Complex.I) *
    (Complex.exp (Complex.I * (a : ℂ) * circleMap 0 R θ) *
      f (circleMap 0 R θ))

/-- Taking norms exposes the real exponential that damps the upper arc. -/
lemma norm_upperSemicircleIntegrand (a R : ℝ) (hR : 0 < R)
    (f : ℂ → ℂ) (θ : ℝ) :
    ‖upperSemicircleIntegrand a R f θ‖ =
      R * Real.exp (-a * R * Real.sin θ) *
        ‖f (circleMap 0 R θ)‖ := by
  -- Use `‖exp w‖ = exp (re w)` and `im z = R * sin θ`.
  simp [upperSemicircleIntegrand, abs_of_pos hR, Complex.norm_exp,
    circleMap, Complex.exp_mul_I, Complex.mul_re,
    Complex.sin_ofReal_re]
  ring_nf

/-- Evaluate the elementary exponential integral by its antiderivative. -/
lemma integral_exp_neg_mul (k b : ℝ) (hk : k ≠ 0) :
    (∫ x in (0 : ℝ)..b, Real.exp (-k * x)) =
      (1 - Real.exp (-k * b)) / k := by
  -- The chain rule shows that `-exp (-k*x) / k` has derivative `exp (-k*x)`.
  have hderiv : ∀ x : ℝ,
      HasDerivAt (fun y : ℝ => -Real.exp (-k * y) / k)
        (Real.exp (-k * x)) x := by
    intro x
    simpa [div_eq_mul_inv, hk] using
      (((Real.hasDerivAt_exp (-k * x)).comp x
        ((hasDerivAt_id x).const_mul (-k))).neg.div_const k)
  -- The fundamental theorem of calculus reduces the integral to endpoint values.
  -- `show` states the continuity fact we need; `fun_prop` proves it from
  -- continuity of multiplication and exp. `.intervalIntegrable` then uses it.
  rw [intervalIntegral.integral_eq_sub_of_hasDerivAt
    (fun x _ => hderiv x)
    ((show Continuous (fun x : ℝ => Real.exp (-k * x)) by
      fun_prop).intervalIntegrable 0 b)]
  simp only [mul_zero, Real.exp_zero]
  ring

/-- The estimate for one half of the arc. We will reuse it by reflection. -/
lemma jordan_half_bound
    (a R M : ℝ) (ha : 0 < a) (hR : 0 < R) (hM : 0 ≤ M)
    (F : ℝ → ℂ)
    (hF : ∀ θ ∈ Icc (0 : ℝ) (Real.pi / 2),
      ‖F θ‖ ≤ R * M * Real.exp (-a * R * Real.sin θ)) :
    ‖∫ θ in (0 : ℝ)..Real.pi / 2, F θ‖ ≤ Real.pi / (2 * a) * M := by
  -- Jordan's sine inequality turns the damping into `exp (-k*θ)`.
  let k : ℝ := 2 * a * R / Real.pi
  -- `dsimp [k]` unfolds our abbreviation; `positivity` checks the signs
  -- using `ha`, `hR`, and the positivity of π.
  have hk : 0 < k := by dsimp [k]; positivity
  have hRM : 0 ≤ R * M := mul_nonneg hR.le hM
  have hpoint : ∀ θ ∈ Icc (0 : ℝ) (Real.pi / 2),
      ‖F θ‖ ≤ R * M * Real.exp (-k * θ) := by
    intro θ hθ
    have hsin := Real.mul_le_sin hθ.1 hθ.2
    -- Multiplication by the negative number `-(a*R)` reverses the inequality.
    have hexponent : -a * R * Real.sin θ ≤ -k * θ := by
      calc
        -a * R * Real.sin θ = -(a * R) * Real.sin θ := by ring
        _ ≤ -(a * R) * (2 / Real.pi * θ) :=
          mul_le_mul_of_nonpos_left hsin
            (neg_nonpos.mpr (mul_nonneg ha.le hR.le))
        _ = -k * θ := by dsimp [k]; ring
    exact (hF θ hθ).trans
      (mul_le_mul_of_nonneg_left (Real.exp_le_exp.mpr hexponent) hRM)

  calc
    -- Bound the norm of the integral by the integral of the real majorant.
    ‖∫ θ in (0 : ℝ)..Real.pi / 2, F θ‖
        ≤ ∫ θ in (0 : ℝ)..Real.pi / 2, R * M * Real.exp (-k * θ) := by
          apply intervalIntegral.norm_integral_le_of_norm_le (by positivity)
          · -- The integral estimate asks for an almost-everywhere bound.
            -- With no exceptional set needed, `filter_upwards []` lets us
            -- prove it for every θ. Here hθ says `0 < θ ∧ θ ≤ π/2`.
            filter_upwards [] with θ hθ
            exact hpoint θ ⟨hθ.1.le, hθ.2⟩
          · exact (show Continuous (fun θ : ℝ =>
              R * M * Real.exp (-k * θ)) by fun_prop).intervalIntegrable _ _
    -- The integral is `(R*M/k) * (1 - exp (-k*π/2))`, at most `R*M/k`.
    _ = R * M * ((1 - Real.exp (-k * (Real.pi / 2))) / k) := by
          rw [intervalIntegral.integral_const_mul, integral_exp_neg_mul k _ hk.ne']
    _ ≤ R * M * (1 / k) := by
          -- `gcongr` reduces this to `1 - exp (...) ≤ 1`, checking that
          -- the common multiplier is nonnegative and the divisor positive.
          gcongr
          exact sub_le_self _ (Real.exp_pos _).le
    -- Substituting `k` cancels the radius: this is the crucial uniform bound.
    _ = Real.pi / (2 * a) * M := by
          dsimp [k]
          field_simp

/-- Add the estimates for the two halves to bound the entire upper arc. -/
lemma jordan_integral_bound
    (a R M : ℝ) (ha : 0 < a) (hR : 0 < R) (hM : 0 ≤ M)
    (F : ℝ → ℂ)
    (hF : ∀ θ ∈ Icc (0 : ℝ) Real.pi,
      ‖F θ‖ ≤ R * M * Real.exp (-a * R * Real.sin θ))
    (hFint : IntervalIntegrable F volume 0 Real.pi) :
    ‖∫ θ in (0 : ℝ)..Real.pi, F θ‖ ≤ Real.pi / a * M := by
  have hmid : 0 ≤ Real.pi / 2 := by positivity
  have hmid_pi : Real.pi / 2 ≤ Real.pi := by linarith [Real.pi_pos]

  -- Apply the half-arc estimate directly on `[0, π/2]`.
  have hleft := jordan_half_bound a R M ha hR hM F (by
    intro θ hθ
    exact hF θ ⟨hθ.1, hθ.2.trans hmid_pi⟩)

  -- Reflect the right half by `θ = π-u`. Its sine is unchanged,
  -- so exactly the same half-arc estimate applies to `u ↦ F (π-u)`.
  have hright := jordan_half_bound a R M ha hR hM
    (fun u => F (Real.pi - u)) (by
      intro u hu
      simpa only [Real.sin_pi_sub] using
        hF (Real.pi - u) ⟨by linarith [hu.2], by linarith [hu.1]⟩)
  rw [intervalIntegral.integral_comp_sub_left] at hright
  have hhalf : Real.pi - Real.pi / 2 = Real.pi / 2 := by ring
  simp only [hhalf, sub_zero] at hright

  -- Integrability on the whole interval gives integrability on both halves.
  have hmid_mem : Real.pi / 2 ∈ uIcc (0 : ℝ) Real.pi := by
    rw [uIcc_of_le Real.pi_pos.le]
    exact ⟨hmid, hmid_pi⟩
  have hleft_int : IntervalIntegrable F volume 0 (Real.pi / 2) :=
    hFint.mono_set (uIcc_subset_uIcc_left hmid_mem)
  have hright_int : IntervalIntegrable F volume (Real.pi / 2) Real.pi :=
    hFint.mono_set (uIcc_subset_uIcc_right hmid_mem)
  calc
    ‖∫ θ in (0 : ℝ)..Real.pi, F θ‖ =
        ‖(∫ θ in (0 : ℝ)..Real.pi / 2, F θ) +
          ∫ θ in Real.pi / 2..Real.pi, F θ‖ := by
            rw [intervalIntegral.integral_add_adjacent_intervals hleft_int hright_int]
    _ ≤ ‖∫ θ in (0 : ℝ)..Real.pi / 2, F θ‖ +
        ‖∫ θ in Real.pi / 2..Real.pi, F θ‖ := norm_add_le _ _
    _ ≤ Real.pi / (2 * a) * M + Real.pi / (2 * a) * M :=
          add_le_add hleft hright
    _ = Real.pi / a * M := by ring

/-- A family satisfying our exponential bound has integrals tending to zero. -/
theorem jordans_lemma_of_majorant
    (a : ℝ) (ha : 0 < a)
    (M : ℝ → ℝ) (hM_nonneg : ∀ R, 0 ≤ M R)
    (hM : Tendsto M atTop (𝓝 0)) (F : ℝ → ℝ → ℂ)
    (hF : ∀ R, 0 < R → ∀ θ ∈ Icc (0 : ℝ) Real.pi,
      ‖F R θ‖ ≤ R * M R * Real.exp (-a * R * Real.sin θ))
    (hFint : ∀ R, IntervalIntegrable (F R) volume 0 Real.pi) :
    Tendsto (fun R => ∫ θ in (0 : ℝ)..Real.pi, F R θ)
      atTop (𝓝 0) := by
  -- A fixed multiple of `M R` still tends to zero.
  have hlimit : Tendsto (fun R => Real.pi / a * M R) atTop (𝓝 0) := by
    simpa using hM.const_mul (Real.pi / a)
  -- Our bound holds for every positive radius, hence eventually as `R → ∞`.
  -- Squeezing the norm below a function tending to zero finishes the proof.
  -- `refine` applies the squeeze theorem, supplying `hlimit` now and leaving
  -- the `?_` as a new goal: the eventual bound on the norm of the integral.
  refine squeeze_zero_norm' ?_ hlimit
  -- `atTop` means "for all sufficiently large R". Eventually R > 0.
  -- `filter_upwards` fixes such an R and names this inequality `hR`;
  -- the remaining goal is our ordinary pointwise integral estimate.
  filter_upwards [eventually_gt_atTop (0 : ℝ)] with R hR
  exact jordan_integral_bound a R (M R) ha hR (hM_nonneg R)
    (F R) (hF R hR) (hFint R)

/-- Jordan's lemma for the anticlockwise upper semicircle, with `a > 0`.
`M R` bounds `‖f z‖` on the radius-`R` arc and tends to zero as `R → ∞`. -/
theorem jordans_lemma
    (a : ℝ) (ha : 0 < a) (f : ℂ → ℂ)
    (M : ℝ → ℝ) (hM_nonneg : ∀ R, 0 ≤ M R)
    (hM : Tendsto M atTop (𝓝 0))
    (hbound : ∀ R, 0 < R → ∀ θ ∈ Icc (0 : ℝ) Real.pi,
      ‖f (circleMap 0 R θ)‖ ≤ M R)
    (hint : ∀ R,
      IntervalIntegrable (upperSemicircleIntegrand a R f) volume 0 Real.pi) :
    Tendsto
      (fun R => ∫ θ in (0 : ℝ)..Real.pi,
        upperSemicircleIntegrand a R f θ)
      atTop (𝓝 0) := by
  -- Apply the general result we just proved to the actual contour integrand.
  apply jordans_lemma_of_majorant a ha M hM_nonneg hM
    (fun R => upperSemicircleIntegrand a R f)
  · intro R hR θ hθ
    -- The norm identity leaves only the given bound `‖f z‖ ≤ M R`.
    rw [norm_upperSemicircleIntegrand a R hR]
    calc
      R * Real.exp (-a * R * Real.sin θ) * ‖f (circleMap 0 R θ)‖
          ≤ R * Real.exp (-a * R * Real.sin θ) * M R := by
            -- The common factor is nonnegative, so `gcongr` leaves just
            -- `‖f (circleMap 0 R θ)‖ ≤ M R`, supplied by `hbound` below.
            gcongr
            exact hbound R hR θ hθ
      _ = R * M R * Real.exp (-a * R * Real.sin θ) := by ring
  · exact hint

end LeanIn

Proof Breakdown

The mathematical helpers

upperSemicircleIntegrand
Writes $e^{iaz}f(z)\,dz$ in terms of $\theta$. Here circleMap 0 R θ is $Re^{i\theta}$ and circleMap 0 R θ * Complex.I is its tangent $dz/d\theta$.
norm_upperSemicircleIntegrand
Separates the three contributions to the norm: the radius $R$, the damping factor $e^{-aR\sin\theta}$, and $|f(z)|$.
integral_exp_neg_mul
Checks the derivative of $-e^{-kx}/k$ and applies the fundamental theorem of calculus. This is the only integral we need to evaluate explicitly.
jordan_half_bound and Real.mul_le_sin
Use the sine inequality $2\theta/\pi\le\sin\theta$ on $[0,\pi/2]$. Multiplication by $-aR$ reverses the inequality; monotonicity of the exponential then gives an integrable upper bound. Substituting $k=2aR/\pi$ cancels $R$.
intervalIntegral.integral_comp_sub_left
Performs the substitution $\theta=\pi-u$. The reversed limits and the minus sign from $d\theta=-du$ cancel, giving the same estimate for the right half without repeating the calculus.
jordan_integral_bound
Restricts the integrability assumption to each half, splits the integral at $\pi/2$, and adds the two norm bounds with the triangle inequality.
jordans_lemma_of_majorant and squeeze_zero_norm'
Turn our estimate into a limit. The prime in squeeze_zero_norm' allows a bound that holds eventually: here it holds for every $R>0$, which is enough as $R\to\infty$.
jordans_lemma
Applies our limit theorem to the actual contour integrand. After rewriting its norm, the only remaining estimate is the hypothesis $|f(z)|\le M(R)$.

Reading the new Lean syntax and tactics

This proof introduces some analysis notation and tactics that deserve a slower first reading. The examples below refer to the exact places where they occur in the proof.

Filter, atTop, 𝓝 0, and Tendsto
A filter describes what it means for a property to hold “eventually”. For real radii, atTop means “for all sufficiently large radii”; the neighbourhood filter 𝓝 0 describes being arbitrarily close to zero. Thus Tendsto M atTop (𝓝 0) says that $M(R)$ is eventually in every neighbourhood of zero. In epsilon language: for every $\varepsilon>0$, there is a threshold beyond which $|M(R)|<\varepsilon$. open Filter makes names from that namespace available without the prefix.
refine squeeze_zero_norm' ?_ hlimit
refine builds a proof from a partially filled-in expression. Each ?_ asks Lean to create a goal for the missing piece. Here the squeeze theorem needs an eventual norm bound and a proof that the upper bound tends to zero. We supply the second with hlimit; the hole leaves only the first to prove. An ordinary _, as in norm_add_le _ _, asks Lean to infer an argument from context.
filter_upwards [eventually_gt_atTop (0 : ℝ)] with R hR
filter_upwards turns an eventual claim into a pointwise proof using eventual facts listed in brackets. Here eventually_gt_atTop (0 : ℝ) says that sufficiently large real numbers are positive. The tactic introduces a radius R and the hypothesis hR : 0 < R. We must then show that the integral at this radius has norm at most $(\pi/a)M(R)$. The next exact supplies precisely that estimate. With several facts in brackets, the tactic works where they all hold.
filter_upwards [] with θ hθ
The earlier use has a different filter: the integral comparison asks for a bound almost everywhere with respect to volume, the usual Lebesgue measure. “Almost everywhere” allows exceptions on a set of measure zero. Our bound holds at every point of the interval, so we need no exceptional-set facts in the brackets. The tactic introduces θ and the premise hθ that $0<\theta\le\pi/2$. Then ⟨hθ.1.le, hθ.2⟩ supplies the closed-interval membership needed by hpoint. This is the same tactic as in the limit argument, but “eventually” here means “almost everywhere”.
gcongr
Short for “generalised congruence”, this tactic uses monotonicity to reduce an inequality between larger expressions to inequalities between their parts. For example, $cu\le cv$ follows from $u\le v$ when $c\ge0$. In the half-arc estimate it reduces the goal to $1-e^{-k\pi/2}\le1$; in the final theorem it leaves $|f(z)|\le M(R)$. It checks the required sign conditions where it can and leaves any unresolved conditions as goals. It does not cancel arbitrary factors regardless of their sign.
show Continuous … by fun_prop
show specifies the type of an intermediate proof. Here we explicitly ask for continuity of an exponential expression. fun_prop assembles standard facts about function properties, such as continuity of products and compositions, to prove it. The following .intervalIntegrable uses continuity to obtain integrability on the finite interval; fun_prop is proving continuity at this step.
dsimp [k] and positivity
dsimp [k] unfolds the local definition of k, exposing $2aR/\pi$. positivity then proves its positivity from the signs of the factors and denominator. The line by dsimp [k]; positivity runs the unfolding first, followed by the sign calculation.
simpa … using … and simp only […]
simpa using h simplifies both the current goal and the type of h, then checks that they match. For example, hM.const_mul (Real.pi / a) gives a limit with value $(\pi/a)\cdot0$; simpa reduces that value to zero. simpa only [Real.sin_pi_sub] using … uses just the named rewrite to identify the reflected sine. Likewise, simp only restricts simplification to the listed rules instead of the usual collection of simplification lemmas.
field_simp, ring, ring_nf, and linarith
field_simp clears denominators, proving or requesting the needed nonzero conditions. Here it finishes the cancellation after unfolding k. ring checks polynomial identities by normalising them; ring_nf puts polynomial expressions in normal form and can also close a goal when both sides then agree. linarith combines linear equalities and inequalities from the context, for example to check that a reflected angle lies in the required interval.
hθ.1, hθ.2, hR.le, hk.ne', and .mpr
These dotted expressions extract or transform existing facts. Membership in Icc is a pair of endpoint inequalities: hθ.1 is the lower bound and hθ.2 the upper bound. From hR : 0 < R, hR.le gives $0\le R$; from hk : 0 < k, hk.ne' gives $k\ne0$. For an equivalence P ↔ Q, .mpr uses the right-to-left implication. Thus Real.exp_le_exp.mpr hexponent turns an inequality between exponents into one between their exponentials. Finally, .trans chains inequalities, and ⟨…, …⟩ packages two facts into a pair.

Caveat

This is the upper-half-plane version for $a>0$. For $a<0$, the matching statement uses a lower semicircle so that the exponential still decays. The theorem assumes integrability of the parameterised integrand on $[0,\pi]$ for every radius; continuity of $f$ on each arc is a common sufficient condition. No holomorphicity assumption is needed for this arc estimate itself.

The decay hypothesis is expressed by a nonnegative function $M$ with $M(R)\to0$ and $|f(z)|\le M(R)$ on the radius-$R$ arc. This is a standard useful form of Jordan's lemma, but it is not a claim that every meromorphic function automatically satisfies the bound.
