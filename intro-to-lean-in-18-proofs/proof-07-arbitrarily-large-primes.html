Lean Statement

∀ n, ∃ p, Nat.Prime p ∧ n < p
Read this as: no matter how large a natural-number bound $n$ we choose, there is a prime number $p$ beyond it.

A standard proof considers $n!+1$. This number has a prime divisor $p$ because all integers have a prime divisor; if $n!+1$ itself is prime, then $n!+1$ is its own prime divisor (I actually missed this point the first time I saw the proof). If $p\le n$, then $p$ appears among the factors of $n!$ (since $n!$ has all integers, and thus all primes, less than itself as factors), so it divides $n!$. By definition, it also divides $n!+1$. Since $a/d + b/d = (a+d)/b$ for all $a,b,d \in \mathbb R$, it would hence also divide their difference 1, which is impossible for a prime. Therefore $n<p$.

The Lean proof follows that argument. It constructs the Euclid number, chooses one of its prime divisors, and rules out the possibility that this divisor is at most $n$.

Why This Proof Matters

This proof turns the usual contradiction argument into Lean data: a prime divisor, a divisibility proof for the factorial, and a final contradiction with a prime dividing $1$.

Schematic Outline

  1. State the theorem as: for every bound $n$, there is a prime greater than $n$.
  2. intro n fixes one arbitrary bound; because it was arbitrary, proving the new goal proves the universal statement.
  3. Set euclidNumber = n.factorial + 1; it cannot be 1 because a factorial is positive.
  4. Choose a prime divisor p of euclidNumber.
  5. Assume p ≤ n. Then Nat.dvd_factorial gives p ∣ n.factorial.
  6. Subtract the two divisible numbers to get p ∣ 1, contradicting primality. Thus n < p.

Lean Proof

import Mathlib

/--
There are arbitrarily large prime numbers.

This is Euclid's factorial argument, with only the elementary fact that a
number other than `1` has a prime divisor supplied by mathlib.
-/
theorem arbitrarily_large_primes :
    ∀ n : ℕ, ∃ p : ℕ, Nat.Prime p ∧ n < p := by
  intro n

  -- Euclid's number is larger than `1`, so it has a prime divisor.
  let euclidNumber := n.factorial + 1
  have heuclidNumber_ne_one : euclidNumber ≠ 1 := by
    dsimp [euclidNumber]
    intro h
    have hzero : n.factorial = 0 := by omega
    exact (Nat.factorial_ne_zero n) hzero
  obtain ⟨p, hpPrime, hpDivides⟩ :=
    Nat.exists_prime_and_dvd heuclidNumber_ne_one

  refine ⟨p, hpPrime, ?_⟩
  by_contra hpAbove
  have hpLe : p ≤ n := Nat.le_of_not_gt hpAbove

  -- A number at most `n` divides `n!`.
  have hpDividesFactorial : p ∣ n.factorial :=
    Nat.dvd_factorial hpPrime.pos hpLe

  -- It also divides `n! + 1`, so it divides their difference, namely `1`.
  have hpDividesOne : p ∣ 1 := by
    have hsubtract : p ∣ euclidNumber - n.factorial :=
      Nat.dvd_sub hpDivides hpDividesFactorial
    simpa [euclidNumber] using hsubtract
  exact hpPrime.not_dvd_one hpDividesOne

Proof Breakdown

The proof follows Euclid's argument: construct n.factorial + 1, choose a prime divisor p of it, and then show that p must be larger than n.

∀ n : ℕ, ...
States that the claim holds for every natural number n. intro n introduces an arbitrary such n so that we can prove the claim for it.
let euclidNumber := n.factorial + 1
Names Euclid's number so that the later divisibility statements are a little more readable.
heuclidNumber_ne_one
Shows that n.factorial + 1 ≠ 1. After intro h, we have the assumption h : n.factorial + 1 = 1. The line have hzero : n.factorial = 0 := by omega uses that assumption to derive n.factorial = 0; it is not claiming that factorial is zero in general. This contradicts Nat.factorial_ne_zero n.
Nat.exists_prime_and_dvd
Supplies a prime divisor of a natural number other than 1. obtain ⟨p, hpPrime, hpDivides⟩ unpacks the result into the prime p, a proof that it is prime, and a proof that p ∣ euclidNumber.
refine ⟨p, hpPrime, ?_⟩
Supplies p as the required witness and hpPrime as the proof that it is prime. The ?_ is a placeholder for the remaining goal, n < p.
by_contra hpAbove
Proves n < p by contradiction. Instead of proving the inequality directly, we assume that it is false. For natural numbers, the negation of n < p means that p ≤ n. The next line makes this explicit: Nat.le_of_not_gt hpAbove gives hpLe : p ≤ n.
Nat.dvd_factorial hpPrime.pos hpLe
Formalises the observation that a positive number no larger than n divides n!. Under the assumption p ≤ n, this gives p ∣ n.factorial.
Nat.dvd_sub'
Transfers divisibility from n! + 1 and n! to their natural-number difference. Since (n! + 1) - n! = 1, we obtain p ∣ 1, contradicting the fact that a prime cannot divide 1.

The key contradiction is therefore: if p ≤ n, then p divides both n! and n! + 1, so it must divide their difference 1. Hence p ≤ n is impossible, leaving n < p.

Caveat

The proof still uses the basic prime-factor fact Nat.exists_prime_and_dvd and standard factorial/divisibility facts. In production code, the shorter exact Nat.exists_prime_gt n is perfectly appropriate; it hides exactly the Euclid argument displayed here.
