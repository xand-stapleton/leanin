Lean Statement

s ∩ t = t ∩ s
Read this as: the elements that belong to both $s$ and $t$ are exactly the elements that belong to both $t$ and $s$. The order in which we name the two sets does not matter.

Two sets are equal when they have the same members. So choose an arbitrary element $x$. If $x\in s\cap t$, then we have two facts: $x\in s$ and $x\in t$. To prove $x\in t\cap s$, we give those same two facts in the opposite order. The reverse implication is identical.

The proof is therefore really the logical fact $P\land Q\iff Q\land P$, with $P$ standing for $x\in s$ and $Q$ standing for $x\in t$.

Why This Proof Matters

This proof introduces two everyday mathlib workflows: prove set equality element by element, then let the simplifier handle membership statements.

Schematic Outline

  1. Use set extensionality to replace $s\cap t=t\cap s$ with a membership statement about an arbitrary element $x$.
  2. Lean changes the goal to $x\in s\cap t\iff x\in t\cap s$.
  3. Split the if-and-only-if into its two directions.
  4. In each direction, unpack the pair of membership proofs and rebuild it in the opposite order.

Lean Proof

import Mathlib

open Set

/--
Set intersection is commutative.
-/
theorem set_intersection_commutative {α : Type u} (s t : Set α) :
    s ∩ t = t ∩ s := by
  -- It is enough to prove that an arbitrary `x` belongs to the left-hand set
  -- exactly when it belongs to the right-hand set.
  ext x

  -- Goal: x ∈ s ∩ t ↔ x ∈ t ∩ s
  constructor

  · -- Forward direction: assume x ∈ s ∩ t.
    intro hx
    -- `hx.1 : x ∈ s` and `hx.2 : x ∈ t`.
    -- The target asks for the same evidence in the order t, then s.
    exact ⟨hx.2, hx.1⟩

  · -- Reverse direction: assume x ∈ t ∩ s.
    intro hx
    -- Now `hx.1 : x ∈ t` and `hx.2 : x ∈ s`.
    exact ⟨hx.2, hx.1⟩

Proof Breakdown

ext x
Uses set extensionality: to prove two sets equal, prove that an arbitrary element $x$ belongs to one exactly when it belongs to the other.
constructor
An $\iff$ goal contains two implications. constructor asks us to prove the forward implication first and the reverse implication second.
intro hx
Moves the assumption for the current implication into the local context and names its proof hx.
hx.1 and hx.2
Membership in an intersection is a conjunction, so its proof contains two components. Dot notation selects the first or second component.
⟨hx.2, hx.1⟩
Angle brackets construct the conjunction required by the target. The order is reversed because the target intersection is $t\cap s$.

Native Lean Version

The same proof can be written without mathlib by representing a set as a predicate and defining intersection directly.

def NativeSet (α : Type) := α → Prop

def NativeInter {α : Type} (s t : NativeSet α) : NativeSet α :=
  fun x => s x ∧ t x

/--
Native Lean version: no mathlib set extensionality tactic is needed.
-/
theorem native_set_intersection_commutative {α : Type}
    (s t : NativeSet α) :
    NativeInter s t = NativeInter t s := by
  funext x
  apply propext
  constructor
  · intro hx
    exact ⟨hx.2, hx.1⟩
  · intro hx
    exact ⟨hx.2, hx.1⟩

Native Lean Breakdown

NativeSet α := α → Prop
Represents a set by the proposition that an element belongs to it.
NativeInter
Defines intersection as conjunction of the two membership predicates.
funext x
Proves equality of predicates by proving equality at an arbitrary input x.
propext
Turns a logical equivalence between propositions into equality of propositions.
constructor and ⟨hx.2, hx.1⟩
Once functions and propositions have been made explicit, the native proof finishes with exactly the same pair-swapping argument as the mathlib proof.

Caveat

This proof is deliberately explicit. Once the logical structure is familiar, the body can be shortened to ext x; simp [and_comm]; when you only need the result, mathlib already provides Set.inter_comm.
