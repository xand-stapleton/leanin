Lean Statement

Nat.Coprime n (n + 1)
Read this as: the only positive natural number dividing both $n$ and its successor $n+1$ is $1$; equivalently, $\gcd(n,n+1)=1$.

Let $d$ divide both $n$ and $n+1$. A common divisor also divides their difference, and $(n+1)-n=1$. Therefore $d$ divides $1$, forcing $d=1$. This is the familiar paper proof.

The Lean proof follows that argument directly, taking $d=\gcd(n,n+1)$. By definition, this $d$ divides both numbers. It therefore divides their difference, so it divides $1$ and must equal $1$.

Why This Proof Matters

This proof turns the usual divisibility argument into explicit Lean steps. It uses only basic facts about greatest common divisors, subtraction and divisibility.

Schematic Outline

  1. Unfold coprimality into the goal $\gcd(n,n+1)=1$.
  2. It is enough to prove that $\gcd(n,n+1)$ divides $1$.
  3. Record that the gcd divides both $n$ and $n+1$.
  4. Use those two facts to show that it divides $(n+1)-n$.
  5. Simplify the difference to $1$ and conclude that the gcd equals $1$.

Lean Proof

import Mathlib

/--
Consecutive natural numbers are coprime.

The mathematical idea is that any common divisor of `n` and `n + 1` must divide
their difference, hence must divide `1`.
-/
theorem consecutive_naturals_coprime (n : ℕ) :
    Nat.Coprime n (n + 1) := by
  -- Coprimality means that the greatest common divisor is `1`.
  show Nat.gcd n (n + 1) = 1

  -- A natural number that divides `1` must itself be `1`.
  apply Nat.eq_one_of_dvd_one

  -- The gcd divides each of the two original numbers.
  have hleft : Nat.gcd n (n + 1) ∣ n :=
    Nat.gcd_dvd_left n (n + 1)
  have hright : Nat.gcd n (n + 1) ∣ n + 1 :=
    Nat.gcd_dvd_right n (n + 1)

  -- A common divisor divides the difference of the two numbers.
  have hdifference : Nat.gcd n (n + 1) ∣ (n + 1) - n :=
    Nat.dvd_sub' hright hleft

  -- The difference of consecutive numbers is `1`.
  have hdifference_eq : (n + 1) - n = 1 := by
    omega
  rw [hdifference_eq] at hdifference
  exact hdifference

Proof Breakdown

Nat.Coprime n (n + 1)
States that $\gcd(n,n+1)=1$.
show Nat.gcd n (n + 1) = 1
Exposes the definition of coprimality as a statement about the greatest common divisor.
Nat.eq_one_of_dvd_one
Reduces the equality goal to proving that the gcd divides $1$.
Nat.gcd_dvd_left and Nat.gcd_dvd_right
Give the two defining divisibility properties of the gcd.
Nat.dvd_sub'
Says that a number dividing two natural numbers also divides their difference.
hdifference_eq
Proves the elementary equality $(n+1)-n=1$ explicitly.
rw [hdifference_eq] at hdifference
Rewrites the difference as $1$ without simplifying away the divisibility evidence.
exact hdifference
Uses the rewritten divisibility fact to close the goal.

The proof does not call a theorem saying that consecutive numbers are coprime. Instead, hleft and hright say that the gcd is a common divisor, while hdifference says that it divides the difference. The last line performs the elementary calculation $(n+1)-n=1$.

Caveat

For ordinary library code, mathlib already has a theorem for this pattern. The same result can therefore be written more quickly as follows:

theorem consecutive_naturals_coprime_via_named_lemma (n : ℕ) :
    Nat.Coprime n (n + 1) := by
  simpa using
    (Nat.coprime_self_add_right (m := n) (n := 1))

This version is shorter, but it requires knowing Nat.coprime_self_add_right and hides the divisor argument inside that library theorem.
