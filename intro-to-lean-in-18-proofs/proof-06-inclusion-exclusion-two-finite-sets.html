Lean Statement

(s ∪ t).card + (s ∩ t).card = s.card + t.card
Read this as: counting the union and then adding back the overlap gives the same total as counting $s$ and $t$ separately.

Classify every relevant element into one of three disjoint regions: only in $s$, only in $t$, or in both. An element in exactly one set contributes once to each side of the equation. An element in both sets contributes twice on the right, once through $|s|$ and once through $|t|$; it also contributes twice on the left, once through the union and once through the intersection.

The more familiar rearrangement is $|s\cup t|=|s|+|t|-|s\cap t|$. The displayed theorem avoids subtraction on natural-number cardinalities by moving the intersection term to the left.

The Lean proof builds this counting argument from scratch by induction on $s$. When a new element is inserted, there are two cases: it is already in $t$, so only the intersection count increases; or it is not in $t$, so only the union count increases. Either way, both sides increase by one.

Why This Proof Matters

This proof turns a visual counting argument into an induction on a finite set. It shows explicitly why inserting one element preserves the identity.

Schematic Outline

  1. Induct on the finite set $s$.
  2. For the empty set, simplify both sides to $|t|$.
  3. In the induction step, insert an element $a$ not already in $s$.
  4. Split into the cases $a\in t$ and $a\notin t$.
  5. If $a\in t$, the intersection and $s$ each gain one element.
  6. If $a\notin t$, the union and $s$ each gain one element.
  7. Use the induction hypothesis to finish the resulting cardinality arithmetic.

Lean Proof

import Mathlib

/--
Inclusion-exclusion for two finite sets.
-/
theorem inclusion_exclusion_two_finite_sets {α : Type} [DecidableEq α]
    (s t : Finset α) :
    (s ∪ t).card + (s ∩ t).card = s.card + t.card := by
  -- Build `s` one element at a time.
  induction s using Finset.induction_on with
  | empty =>
      -- The union with the empty set is `t`; the intersection is empty.
      simp
  | @insert a s ha ih =>
      -- Decide whether the new element is already counted by `t`.
      by_cases hat : a ∈ t
      · -- If `a ∈ t`, the intersection and `s` both gain one element.
        simp [ha, hat]
        omega
      · -- If `a ∉ t`, the union and `s` both gain one element.
        simp [ha, hat]
        omega

Proof Breakdown

[DecidableEq α]
Allows Lean to decide when two elements of α are equal, which finite-set union and intersection need computationally.
Finset α
A finite set of elements of type α.
.card
Counts the elements of a finite set. The dot is Lean's dot notation: s.card is another way to write Finset.card s. Parentheses determine what is counted, so (s ∪ t).card is the number of elements in the whole union.
induction s using Finset.induction_on
Proves the result first for the empty set, then proves that inserting a fresh element preserves it.
| empty =>
The vertical bar | starts one branch of the induction. This branch handles the empty finite set. Here | is Lean syntax; it does not mean absolute value or cardinality.
| @insert a s ha ih =>
Starts the insertion branch. The @ asks Lean to expose all the branch arguments so that we can name them. Here a is the new element, s is the smaller finite set, ha proves that a ∉ s, and ih is the induction hypothesis for s. The arrow => marks the beginning of the proof for this branch.
ha : a ∉ s
Records that the element inserted in the induction step is genuinely new, so the cardinality of $s$ increases by one.
by_cases hat : a ∈ t
Separates the two possible ways the new element contributes to the union and intersection.
simp [ha, hat]
Simplifies insertion, membership and cardinality in the appropriate case.
omega
Uses the induction hypothesis to finish the remaining natural-number arithmetic.

If $a\in t$, inserting $a$ into $s$ does not enlarge $s\cup t$, but it does enlarge $s\cap t$. If $a\notin t$, inserting $a$ enlarges $s\cup t$, but not $s\cap t$. The right-hand side always gains one because $s$ gains one. This is exactly the bookkeeping performed by the two branches.

Caveat

For ordinary library code, mathlib already provides the completed inclusion–exclusion theorem. The proof can therefore be shortened to:

import Mathlib

open Finset

universe u

theorem inclusion_exclusion_two_finite_sets_via_mathlib
    {α : Type u} [DecidableEq α] (s t : Finset α) :
    (s ∪ t).card + (s ∩ t).card = s.card + t.card := by
  exact Finset.card_union_add_card_inter s t

This is the concise version to use when the counting argument itself is not the subject of the proof.
